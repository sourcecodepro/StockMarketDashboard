## 2. Technical Scope & System Objectives

The Executive Report Export Engine extends the platform's decision-support capability by translating browser state into two production-grade, offline deliverables:

1. **Executive Briefing PDF Document (`.pdf`)**: A single-page or two-page executive presentation containing branded headers, Data Health Index ($DHS$) audit metrics, fundamental/technical takeaways, portfolio risk-adjusted return summaries, and tabular peer evaluations.
2. **Institutional Financial Model (`.xlsx`)**: A structured multi-tab Excel workbook formatted with dark institutional headers, formatted accounting currency/percentage masks, and raw audit logs.

## 3. Detailed Component Specifications

### 3.1 PDF Engine Specification (`core/pdf_exporter.py`)

* **Core Engine**: `ReportLab` (`SimpleDocTemplate`, `Paragraph`, `Table`, `Spacer`).
* **Visual Aesthetic**: Synchronized with the **Formal Dark Slate** theme palette (`#0F172A` headers, `#1E293B` containers, `#22C55E` bullish accents, `#EF4444` bearish accents).
* **Document Layout & Structure**:
* **Header Banner**: Corporate Title, Asset Ticker/Name, Target Currency Symbol, Generation Timestamp, and Data Health Score Badge.
* **Section 1 (Executive Summary Takeaways)**: Bullet points generated by `core/insight_engine.py` styled as callout containers.
* **Section 2 (Technical & Fundamental Matrix)**: Two-column key-value grid rendering EMA alignments, 14-period RSI, MACD signal states, P/E ratios, and Debt-to-Equity parameters.
* **Section 3 (Peer Valuation Comparison Table)**: Compact grid comparing target asset multiples against industry sector medians.
* **Section 4 (Portfolio Standings & Risk Exposure)**: Invested Capital, Current Valuation, Unrealized P&L, Portfolio Beta ($\beta_p$), and Sharpe Ratio ($SR$).



| PDF Section | Visual Style / Layout | Key Data Included |
| --- | --- | --- |
| **Header** | Full-width Slate Banner (`#0F172A`) | Symbol, Company Name, DHS Badge %, Date/Time Stamp |
| **Takeaways** | Muted Slate Card (`#1E293B`) | Bulleted Rule Matrix Results |
| **Metrics Grid** | 2-Column Balanced Table | Price, RSI, EMA 20/50/200, MACD, P/E, Debt/Equity |
| **Peer Matrix** | Slate Header Table with Alternating Rows | P/E, P/S, EV/EBITDA, Op Margin %, ROE % |
| **Portfolio Risk** | 4-Card Summary Grid | Total Invested, Market Value, P&L ($/%), Beta, Sharpe Ratio |

### 3.2 Excel Engine Specification (`core/excel_exporter.py`)

* **Core Engine**: `openpyxl` with custom cell styling (`Font`, `PatternFill`, `Border`, `Alignment`).
* **Workbook Structure (4 Multi-Tab Worksheets)**:
1. **`Executive Summary`**: High-level key performance indicators (KPIs), investment standing, decision bullet points, and Data Health Score audit summary.
2. **`Stock Analytics`**: Full technical indicator history (OHLCV, EMA 20/50/200, RSI 14, MACD) and 5-Point Fundamental Radar normalized scores.
3. **`Portfolio Terminal`**: Detailed position log (Ticker, Buy Date, Quantity, Buy Price, Current Price, Invested, Market Value, P&L, Weight) and cross-asset Pearson correlation matrix.
4. **`Pipeline Telemetry Log`**: Historical sanitization audit records, missing field counts, and imputation methods.


* **Formatting Standards**:
* **Headers**: `#0F172A` background fill with white bold text (`#FFFFFF`).
* **Currency Formatting**: Localized accounting format (`$#,##0.00` or `₹#,##0.00`).
* **Percentage Formatting**: Standard two-decimal percentage (`0.00%`).
* **Auto-Column Sizing**: Dynamic column width fitting based on string length padding.

### 3.3 UI Trigger Integration Specifications

#### 1. Navbar / Modal Component Additions (`components/navbar.py`)

Add two distinct export buttons to the Executive Briefing Modal:

* `btn-export-pdf`: Primary download button with PDF icon (`bi-file-earmark-pdf`).
* `btn-export-excel`: Secondary download button with Excel icon (`bi-file-earmark-excel`).
* Download Handlers: Add `dcc.Download(id="download-pdf")` and `dcc.Download(id="download-excel")` wrappers to the DOM layout.

#### 2. Callback Binding Contract (`app.py`)

* **Trigger Inputs**: `Input("btn-export-pdf", "n_clicks")` and `Input("btn-export-excel", "n_clicks")`.
* **State Inputs**: `State("session-store", "data")`.
* **Callback Payload Handlers**:
* `dcc.send_bytes(generate_pdf_bytes(data), filename=f"Executive_Report_{ticker}.pdf")`
* `dcc.send_bytes(generate_excel_bytes(data), filename=f"Executive_Terminal_{ticker}.xlsx")`
