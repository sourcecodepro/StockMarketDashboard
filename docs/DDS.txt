## 3. Modular System Architecture & Data Governance Pipeline

### 3.1 Data Contract & Schema Validation (`core/schemas.py`)

Incoming payloads from external endpoints are coerced into strict Pydantic schemas before entering the calculation engines:

* **`MarketDataSchema`**: Enforces strict typing on OHLCV DataFrames. Verifies that `Date` is indexable, volume is non-negative ($\text{Volume} \ge 0$), and `Close` prices are strictly positive floats.
* **`FundamentalDataSchema`**: Enforces numerical boundaries on financial ratios:

$$\text{P/E} \in [0.0, 1000.0], \quad \text{Debt/Equity} \ge 0.0, \quad \text{ROE} \in [-5.0, 5.0]$$



### 3.2 Domain-Aware Sanitization & Imputation (`core/sanitization.py`)

To prevent sparse or missing API data from crashing downstream visualizers or mathematical engines, the pipeline applies four deterministic imputation strategies:

1. **Valuation Multiples (P/E, P/S, EV/EBITDA):** Missing attributes are replaced with the pre-calculated median for that stock's industry sector (`data/sector_medians.json`). The field is flagged as `imputed=True`.
2. **Time-Series Prices (OHLC):** Gaps from non-trading days or missing ticks use Forward-Fill (`ffill`) followed by Backward-Fill (`bfill`) to preserve indicator continuity.
3. **Derived Ratio Fallbacks:** If composite metrics like Debt-to-Equity are returned as `Null`, the engine dynamically derives them from root balance sheet items:

$$\text{Debt-to-Equity} = \frac{\text{Total Liabilities}}{\text{Total Stockholder Equity}}$$


4. **Volume Channels:** Null volume values are filled with `0` to prevent artificial breakout signals in momentum monitors.

### 3.3 Data Health Index & Telemetry (`core/telemetry.py`)

Every data request calculates a **Data Health Score ($DHS$)** to quantify data reliability:

$$DHS = \left( \frac{N_{\text{required}} - N_{\text{imputed}}}{N_{\text{required}}} \right) \times 100$$

* **Health Thresholds:**
* $DHS \ge 90\%$: **High Quality** (Green Badge in UI)
* $70\% \le DHS < 90\%$: **Degraded / Sector Imputed** (Yellow Badge in UI)
* $DHS < 70\%$: **Low Confidence** (Orange Badge + Alert Flag)


* **Telemetry Audit:** Imputation events append structured JSON logs to `logs/pipeline_telemetry.log` specifying timestamp, ticker, missing fields, and applied remediation.

### 3.4 Circuit Breaker & API Fetcher (`core/data_engine.py`)

Wraps `yfinance` with an active Circuit Breaker pattern using `Flask-Caching`:

* **Normal Mode:** Fetches live/hourly data; caches responses for $TTL = 3600\text{s}$.
* **Trip Condition:** Triggers if 3 consecutive requests fail or time out (> 5.0s).
* **Fallback Mode:** Serves static snapshot data from `data/fallback_cache.parquet` and flags the global system status as `"Offline Mode / Cached Data"`.

## 4. Technical & Risk Computation Engines

### 4.1 Technical Momentum Engine (`core/technicals.py`)

Vectorized operations via Pandas and NumPy calculate technical indicators across daily price series:

* **Exponential Moving Averages:**

$$EMA_t = \left( \text{Price}_t \times \left( \frac{2}{N + 1} \right) \right) + \left( EMA_{t-1} \times \left( 1 - \frac{2}{N + 1} \right) \right) \quad \text{for } N \in \{20, 50, 200\}$$


* **Relative Strength Index (RSI):** Calculated over a 14-day window:

$$RS = \frac{\text{EMA}_{14}(\text{Gains})}{\text{EMA}_{14}(\text{Losses})}, \quad RSI = 100 - \left( \frac{100}{1 + RS} \right)$$


* **MACD Line & Histogram:**

$$\text{MACD} = EMA_{12}(\text{Close}) - EMA_{26}(\text{Close}), \quad \text{Signal} = EMA_9(\text{MACD})$$



### 4.2 Portfolio & Risk Engine (`core/risk_engine.py`)

* **Portfolio Beta ($\beta_p$):** Weighted systematic risk relative to the market benchmark ($M$):

$$\beta_p = \sum_{i=1}^{K} w_i \cdot \frac{\text{Cov}(R_i, R_M)}{\text{Var}(R_M)}$$


* **Annualized Sharpe Ratio ($SR$):** Assumes 252 trading days and risk-free rate $R_f = 4.2\%$:

$$SR = \frac{\bar{R}_p - R_f}{\sigma_p \cdot \sqrt{252}}$$


* **Correlation Matrix:** Calculates pairwise Pearson correlation matrix $C_{i,j}$ across holding daily returns.

## 6. State Management & Callback Topology

To eliminate circular callback errors, race conditions, and duplicate API requests, the app uses a **Single Source of Truth** pattern anchored by a browser-memory store (`dcc.Store`).

```text
       ┌───────────────────────────────────────────────────────────────┐
       │ User Event (Select Ticker OR Toggle Theme Switcher Dropdown)  │
       └──────────────────────────────┬────────────────────────────────┘
                                      │
                     ┌────────────────┴────────────────┐
                     │                                 │
            [Ticker Selected]                  [Theme Toggled]
                     │                                 │
                     ▼                                 ▼
 ┌──────────────────────────────────────┐  ┌──────────────────────────────────────┐
 │ Master Data Callback (app.py)        │  │ Theme Callback (components/navbar.py)│
 │ 1. Fetch yfinance Data               │  │ 1. Swap CSS Link Href                │
 │ 2. Run Pydantic Schema Check         │  │ 2. Update Plotly Figure Theme Tokens │
 │ 3. Execute Imputation & DHS Scoring  │  └──────────────────────────────────────┘
 │ 4. Calculate Indicators & Risk Math  │
 └──────────────────┬───────────────────┘
                    │
       [Serializes Clean JSON]
                    │
                    ▼
 ┌──────────────────────────────────────┐
 │    dcc.Store(id='session-store')     │
 └──────┬───────────────┬───────────────┘
        │               │
        ▼               ▼
 ┌─────────────┐ ┌─────────────┐
 │ Render      │ │ Render      │
 │ Charts      │ │ Insights    │
 └─────────────┘ └─────────────┘

```

## 7. Decision Support & Executive Insight Engine (`core/insight_engine.py`)

The insight engine evaluates raw metrics against a deterministic rule matrix to generate automated bullet points:

```python
# Rule Engine Decision Matrix
IF RSI < 30 AND Current_Price > EMA_200:
    FLAG "Oversold Pullback in Secular Uptrend (Potential Swing Entry)"
ELIF RSI > 70 AND Current_Price < EMA_20:
    FLAG "Overbought Reversal Danger (Take Profit / Tighten Stops)"

IF Forward_PE < Sector_Median_PE * 0.75 AND Debt_To_Equity < 0.5:
    FLAG "Fundamentally Undervalued with Strong Balance Sheet"

IF Portfolio_Beta > 1.35:
    FLAG "High Beta Exposure: Portfolio is highly sensitive to market downturns"

```

* **Export Functionality:** Users can trigger a 1-click **Executive Summary Export**, rendering an inline print-ready HTML modal or downloadable summary of active portfolio metrics and selected stock insights.
